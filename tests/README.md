# Public prototype baseline

Run `node --test tests/prototype-baseline.test.cjs` with Node 18 or newer.

This dependency-free harness executes the existing inline prototype script in a small DOM stub and checks protected catalog, random selection, sequencing, custom activity, screening, escaping and explicit acceptance behavior. Seeded repetitions exercise ordering without flaky random coverage.

These checks do not prove fixed-event feasibility, time budgets, household persistence, ranking quality, or browser accessibility. DOM hooks and copy checks are limited source checks. Keyboard, assistive-technology, contrast, responsive layout and reduced-motion interaction require real browser QA before release. New planning trust boundaries need separate tests when implemented.

No household records, proprietary ranking logic, new collection or runtime changes are included. Keep controlled architecture and security evidence in internal documentation.
