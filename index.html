SpinFamily

A playful family evening planner for getting past “what should we do tonight?”

Public prototype: plans are created from curated categories and random selection. This version does not use machine learning, cloud sync, weather data, or personalized recommendation models.

Quick Start

  1. Choose the family member helping with the decision.
  2. Spin the wheel.
  3. Review the three selected activities in their suggested order.
  4. Spin again if the plan does not fit tonight.
  5. Add a custom activity from the Activities tab if needed.

What the prototype does

SpinFamily currently combines curated activity lists with random selection and a small set of sequencing rules. Chores are placed before leisure/wind-down when present, self-care is placed toward the end, and Early bedtime routine is always the final activity. The recommendation engine is not yet context-aware.

What comes next

Planner Engine v2 will add time constraints, household context, activity metadata, repetition controls, richer sequencing constraints, and explainable scoring before any machine-learning layer is considered.

About SpinFamily

SpinFamily is designed to reduce family evening decision fatigue through a quick, participatory planning experience.

Current prototype capabilities

  • Four curated activity categories
  • Random three-category evening plans with simple logical sequencing
  • Session-only custom activities
  • Basic client-side family-friendly text screening for custom activity names

Not implemented in this version

  • Machine-learning recommendations
  • Personalized member scoring
  • Cloud accounts or cross-device sync
  • Weather-aware suggestions
  • Validated streak or variety analytics

Prototype status: public beta/proof of execution. Public deployment does not represent production security, privacy, or ML approval.
